# 🎵 AI Music Generator

## CodeAlpha AI Internship - Task 3

### 📌 Project Overview

AI Music Generator is a Flask-based web application that generates simple AI-inspired melodies in MIDI format. Users can choose a music style and generate a downloadable MIDI file.

---

## 🚀 Features

- 🎹 Piano Music Generation
- 🎼 Classical Music Generation
- 🎷 Jazz Music Generation
- 🎵 AI Inspired Melody Generator
- 💾 MIDI File Generation
- ⬇ Download Generated Music
- 🌐 Responsive User Interface
- ⚡ Flask Backend

---

## 🛠 Technologies Used

- Python
- Flask
- music21
- HTML5
- CSS3
- JavaScript

## ▶️ Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
